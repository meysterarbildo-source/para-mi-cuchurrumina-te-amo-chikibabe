# Para mi cuchurrumina, te amo chikibabe

Sitio web estático de **Nuestra Historia**.

## Publicación

El proyecto incluye `.nojekyll` y puede publicarse con GitHub Pages cuando el repositorio se configure como público o se habilite Pages según la configuración de la cuenta.

## Configuración opcional

La integración con Supabase se encuentra preparada en `js/config.js`, pero permanece desactivada y sin credenciales.
